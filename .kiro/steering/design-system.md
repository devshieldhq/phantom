# PHANTOM Design System
Visual direction: hybrid CRT terminal + modern dashboard.
Canvas #090d0c; panels #101715; borders #24352e; signal green #9cff6b; muted text #81958a.
Use mono for terminal labels and commands; readable sans-serif for long copy.
Subtle grid, thin borders, restrained glow, clear focus states.
Avoid excessive scanlines, illegible low contrast, and purely decorative animations.
Mobile-first responsive layouts. Every interaction must work by keyboard and touch.
